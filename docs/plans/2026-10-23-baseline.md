## What each command touches

| Command | Effect |
| --- | --- |
| `npm run typecheck` (`tsc --noEmit`) | Read-only. |
| `npm run test:unit` | Read-only (no database). |
| `npm run test:integration` | Applies pending migrations to `jobhunter_test`, then TRUNCATEs it between cases. |
| `npm run test:failure` | Spawns real worker/API processes against `jobhunter_test`. |
| `npm run verify` | Disk check + `tsc --noEmit` + full vitest run; integration files TRUNCATE `jobhunter_test`. |
| `npm test` | vitest watch mode; any integration file TRUNCATEs `jobhunter_test`. |
| `prisma migrate deploy` | Applies pending migrations to `DATABASE_URL`. Not a reset. |

No command in this repository resets a schema. The destructive step is `TRUNCATE`, and it can only reach a database whose name ends in `_test`.
